# Smart Campus Companion App

The **Smart Campus Companion** is a mobile application designed to assist university students in managing their campus life more easily. It provides quick access to important campus information in one simple app.

This project is created as a student mobile application using modern Android development tools.

## Features
- User login
- Dashboard with quick access menu
- Campus information
- Announcements
- Schedule
- Settings

## Built With
- Kotlin
- Android Jetpack Compose
- Material 3

## Purpose
This app is developed as a **student project** to demonstrate Android UI design and basic application flow.
