# Smart Campus Companion App

## App Description
The Smart Campus Companion is a mobile app made to make college life easier for both students and staff. It’s a one-stop shop where you can find school info, manage your tasks, and get news from the campus in real-time.

This project is created as a student mobile application using modern Android development tools.

---

## Features

### For Students

- Home Dashboard  
  View tasks, announcements, and school information in one place.

- Task Tracker  
  Manage deadlines and schedules. Data is stored in the cloud to prevent loss.

- Campus Info  
  Browse information about colleges, including:
  - Undergraduate and graduate course lists  
  - Organizational charts (with photos)  
  - Social media links and contact details  
  - Student organization information  

- Latest News  
  Receive real-time alerts and browse announcements.

- User Profile  
  Securely create and manage your student profile.

---

### For Admins

- Admin Dashboard  
  Access tools to manage the system.

- Post News  
  Create, update, and manage announcements.

- Student List  
  View and securely manage student records.

- Special Access  
  Dedicated screens and settings for administrators.

---

## Extra Features

- Cloud Sync  
  Automatically synchronizes data with Firebase.

- Smart Alerts  
  Sends background reminders for important deadlines.

---

## Built With

- Kotlin (Programming Language)  
- Jetpack Compose (UI Framework)  
- Room (Local Database)  
- Firebase (Authentication, Database, Notifications)  
- WorkManager (Background Tasks)
